# Portfolio de Marie Cruciani

Site statique d'une seule page (`index.html`), hébergé sur GitHub Pages. Pas de build, pas de dépendances.

- Langue du site et des échanges : français.
- La DA n'est pas encore définie : toutes les couleurs, polices et arrondis sont des variables CSS dans `:root` en haut de `index.html`. Changer la DA = modifier ces variables, pas les règles des composants.
- Sections (ancres) : #parcours #photographie #3d #figurines #creas #logo #typo #pub #poster #site-web #planner #contact.
- Les projets viennent de Behance (https://www.behance.net/mariecruciani). Les images de couverture sont chargées depuis le CDN Behance ; chaque `.ph` affiche un texte de secours si l'image ne charge pas.
- Garder le site lisible sur téléphone (pas de défilement horizontal) et en thème clair comme sombre.
